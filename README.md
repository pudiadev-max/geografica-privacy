# GeoGrafica — Informativa sulla privacy

Questo repository ospita unicamente l'informativa sulla privacy dell'app Android
**GeoGrafica** (`com.pudi.geografica`), pubblicata tramite GitHub Pages perché Google Play
richiede un URL pubblico.

👉 **https://pudiadev-max.github.io/geografica-privacy/**

I confini dei quartieri usati dall'app sono in un repository separato:
[geografica-hoods](https://github.com/pudiadev-max/geografica-hoods).
